Customization Guide
To change the name: Update the <title> tag and the “ঘরের সদাই” (Ghorer Sodai) text within the .logo class

To change colors: Modify the :root variables in the CSS

To add products: Copy and paste a new <article class="product"> block inside the .products container

To change images: Replace the link in each <img src="..."> attribute with the URL of your own image
